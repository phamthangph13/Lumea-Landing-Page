# LUMÉA — Vietnamese House of Scent & Ritual

Landing page chính thức giới thiệu thương hiệu và hệ sinh thái **LUMÉA** (Công ty Cổ phần LUMÉA - LUMÉA ., JSC).

---

## 🌿 Về LUMÉA

- **Định vị:** Vietnamese House of Scent & Ritual (Ngôi nhà hương Việt & Nghi thức chăm sóc thân tâm).
- **Triết lý:** **CĂN · MINH · HÒA**
  - **CĂN (Gốc Việt):** Điểm tựa văn hóa, cội nguồn bản sắc, chất liệu và hương thơm bản địa.
  - **MINH (Trí sáng):** Tinh thần khoa học, lõi công thức chuẩn mực, tư duy đổi mới, kết nối chiều sâu.
  - **HÒA (Hài hòa):** Sống thuận tự nhiên, cân bằng thân tâm, gắn kết cộng đồng và môi trường.
- **Tầm nhìn:** Đưa những giá trị có thật của văn hóa Việt bước vào đời sống thế hệ mới bằng mùi hương, thiết kế đương đại và khoa học nghiên cứu bài bản.

## 🛠️ Công nghệ sử dụng

- **Framework:** Nuxt.js 2 (Vue 2 SSR & Static Generation)
- **Animation & Visuals:** GSAP, Three.js, ASScroll Smooth Scroll, WebGL Shaders
- **Typography:** Barlow Condensed, Plus Jakarta Sans
- **Styling:** SCSS với hệ thống Design Token màu sắc thảo mộc bản địa & terracotta

## 🚀 Cài đặt và Chạy thử

```bash
# Cài đặt dependencies
npm install

# Khởi chạy môi trường phát triển (localhost:3000)
npm run dev

# Xây dựng bản production
npm run build

# Tạo static bundle xuất bản
npm run generate

# Chạy production server
npm run start
```
